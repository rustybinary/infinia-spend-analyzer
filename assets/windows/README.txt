Infinia Spend Analyzer - Windows
================================
Everything runs on your own PC. Your PDFs and password are never uploaded anywhere.

1. Install Python 3 once (https://www.python.org/downloads/ - tick "Add python.exe to PATH"),
   or in Command Prompt:  winget install Python.Python.3.12
2. Unzip this folder anywhere. (If Windows blocks the zip: right-click the zip > Properties > Unblock, then unzip.)
3. Double-click Start-Infinia-Spend-Analyzer.bat
   - First run installs a few packages (1-2 min, internet needed).
   - If Windows shows "Windows protected your PC": click More info > Run anyway.
4. Your browser opens the app. Upload the PDFs, enter the password, done.

Closing the browser tab stops the app. Saved category choices live in
%LOCALAPPDATA%\CCSorter\category_overrides.json
